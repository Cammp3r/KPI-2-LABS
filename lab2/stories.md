# User Stories

| ID | Актор | Історія |
|---|---|---|
| US-01 | Гість | Як Гість, я хочу переглядати список задач і фільтрувати його за складністю та тегами, щоб знайти задачу під свій рівень і тему. |
| US-02 | Гість | Як Гість, я хочу зареєструватися за username, email і паролем, щоб надсилати рішення. |
| US-03 | Гість | Як Гість, я хочу увійти через GitHub або Google, щоб не створювати окремий пароль. |
| US-04 | Користувач | Як Користувач, я хочу надіслати рішення задачі обраною мовою, щоб дізнатися, чи проходить воно всі тести. |
| US-05 | Користувач | Як Користувач, я хочу бачити історію своїх надсилань, щоб відстежувати прогрес. |
| US-06 | Користувач | Як Користувач, я хочу опублікувати розбір на основі свого прийнятого рішення, щоб поділитися підходом з іншими. |
| US-07 | Користувач | Як Користувач, я хочу оформити Premium, щоб отримати доступ до Premium-задач. |
| US-08 | Premium-користувач | Як Premium-користувач, я хочу відкривати й розв'язувати Premium-задачі, щоб тренуватися на ширшому наборі задач. |
| US-09 | Адміністратор | Як Адміністратор, я хочу створювати задачі з тест-кейсами й тегами, щоб поповнювати каталог. |
